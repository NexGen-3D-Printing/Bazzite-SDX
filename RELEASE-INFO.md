# Bazzite-SDX Release Information

This file documents the Bazzite-SDX image configuration and release history. For per-build app/kernel **versions**, see the auto-updated [**latest** GitHub release](https://github.com/NexGen-3D-Printing/bazzite-sdx/releases/tag/latest) (generated by `build.yml` from the built image).

## Current Configuration

- **Image:** `ghcr.io/nexgen-3d-printing/bazzite-sdx:latest`
- **Base:** `ghcr.io/ublue-os/bazzite-dx:stable` (Bazzite-DX)
- **Fedora/Surface metadata (repo config):** configured for Fedora 45 / `*.surface.fc45` context where stated (actual base OS version follows the upstream Bazzite-DX `:stable` image at build time)
- **Distribution:** rebase-only (no custom USB installer ISO)
- **Builds:** GitHub Actions `build.yml` publishes `:latest` and dated tags, signs with Cosign, and updates the `latest` release notes

## What's Included

### Linux Surface kernel stack
Installed from the [linux-surface](https://github.com/linux-surface/linux-surface) Fedora repository:
- `kernel-surface`
- `iptsd`
- `libwacom-surface`, `libwacom-surface-data`
- `surface-control`
- `surface-dtx-daemon`

The build removes the stock kernel to ensure exactly one `/usr/lib/modules` kernel directory (bootc requirement).

### Apps added by image build (system Flatpaks)
- **Brave Browser** — `com.brave.Browser` (Flathub); Firefox RPM removed during image build when present
- **OpenCode** — `ai.opencode.opencode` (Flathub)
- **SolidCraft** — `io.tangencylabs.solidcraft` (SolidCraft Flatpak repo)
- **ArtCraft** — upstream Flatpak bundle from `storytold/artcraft` releases
- **Mission Center** — `io.missioncenter.MissionCenter` (Flathub)

Apps without Flatpak support are dropped from the image build (planned for `ujust` recipes later).

### Bazzite-DX base
Includes the Bazzite-DX experience provided by the upstream base image (gaming + developer tooling). Refer to [Bazzite-DX](https://github.com/ublue-os/bazzite-dx) / [Bazzite](https://bazzite.gg/) for upstream feature details.

## Install (rebase)

```bash
sudo bootc status
sudo bootc switch ghcr.io/nexgen-3d-printing/bazzite-sdx:latest
sudo reboot
```

Verify:

```bash
sudo bootc status
uname -r
rpm -qa | grep -E "(kernel-surface|iptsd|libwacom-surface|surface-)"
cosign verify --key cosign.pub ghcr.io/nexgen-3d-printing/bazzite-sdx:latest
```

- Surface Pro 3–9 (Pro X: partial/varies)

Support depends on upstream [linux-surface](https://github.com/linux-surface/linux-surface) kernel/firmware status for each model.

## Release History

### 2026-11 (current line)
- Base switched to **Bazzite-DX** (`ghcr.io/ublue-os/bazzite-dx:stable`)
- Added apps as **system Flatpaks** where supported: **Brave** (Firefox RPM removed), **OpenCode** (Flathub), **SolidCraft**, **ArtCraft**, **Mission Center**. Apps without Flatpak support (e.g., Unsloth Desktop) dropped from the image (planned for `ujust` recipes).
- `build.yml` detects base OS and Flatpak app versions and updates the `latest` GitHub release
- **ISO/Google Drive distribution removed**; project uses bootc rebase workflow

### Version 1.0.0 (2026-11-06)
- Initial Bazzite-SDX release
- Linux Surface kernel packages installed on a Bazzite-based image
- Automatic builds/publishing via GitHub Actions
